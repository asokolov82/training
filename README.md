*************Описание для задания Модуля 25
Чат клиент-серверный, мультиклиентный.
используемая база данных - PostgreSQL, имя базы - chat
созданы два пользователя: Алекс и Stas с паролями 123
Описание работы:
когда пользователь логинится, сохраняем в теблице session номер его сетевой сессии и логин. когда пользователь разлогинивается или выходит, удаляем из таблицы session запись с его логином, таким образом имеем постоянно актуальную таблицу онлайн пользователей. Так же рассылаем всем активным пользователям в чате сообщение кто вышел из чата.
После входа пользователя проверяем, есть ли для него личные сообщения, если есть то отправляем их адресату и удаляем из таблицы priv_msg.
Когда пользователь в чате отправляет личное сообщение, то проверяем если адресат в сети то сразу отправляем, если адресата не существует то уведомляем отправителя, если адресат существует но не в сети, сохраняем сообщение в таблице priv_msg.
когда пользователь пишет сообщение в общий чат, оно рассылается всем активным пользователям по таблице session и сохранятся в таблице message

Таблицы:
message - для хранения общего чата
priv_msg - для хранения личных сообщений, пока они не отправлены получателю.
session - для хранения текущих сессий подключенных пользователей, очищается при запуске сервера
users - для хранения логинов и паролей пользователя
